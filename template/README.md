# Developer Portfolio Template

An open-source, no-build portfolio template for Software, AI, ML, and Data Engineers.

## Use it in five minutes

1. Fork or download this folder.
2. Edit [`config.js`](./config.js). This is the only file you need to customize.
3. Replace `assets/resume.pdf` if you want a resume link.
4. Open `index.html` locally, or enable GitHub Pages with `template` as the publishing folder.

The template is plain HTML, CSS, and vanilla JavaScript. It has no npm, framework, bundler, or build step. Empty optional links and fields are hidden automatically.

## Themes

Use the Theme menu in the header to preview Midnight, Aurora, and Paper. Set the default in `config.js` under `theme.default`.

## Deploy with GitHub Pages

For the simplest deployment, copy the contents of `template/` to the root of a new repository. In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, and select your default branch and `/ (root)`.
